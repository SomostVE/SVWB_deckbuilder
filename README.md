# Shadowverse Deck Assistant

Static GitHub Pages deck workshop for **Shadowverse: Worlds Beyond**.

The project uses the official English Deck Portal data as its generated card database, then adds a separate assistant layer for discovery, deck construction and analysis.

## Main features

- Official English card data and card images
- Class + Neutral card pool
- Set / Type / Rarity / Trait / Keyword filters
- Resizable high-density card grid
- Left click adds a card; right click removes one
- Interactive hover profiles
- Generated / Token cards hidden from the normal deck pool by default
- Generated cards grouped under the cards that create them
- Reverse `Generated by` navigation
- Direct relations, same-archetype cards and common packages in card profiles
- Functional role inference: Draw, Removal, Board Clear, Heal, Ramp, Finisher, Early Game, Combo Piece, Generate
- Advanced search syntax such as `role:draw`, `keyword:storm`, `trait:Officer`, `related:"Bat"`
- Discover mode from any card
- Favorites / watchlist
- Personal excluded-card blacklist
- Owned-card counters
- Core / Optional / Tech deck marks
- Live deck analysis, mana curve, card types, roles, keywords and basic warnings
- Generated-card dependency analysis
- Undo / Redo deck history
- Saved deck variants
- Deck comparison
- JSON import/export
- Shareable deck URLs
- Curated card packages with quantity presets and optional prompt-on-add behavior
- Automatic weekly card database updates through GitHub Actions

## Generated vs selectable cards

Cards from the Token set, cards flagged by the portal as tokens, or cards with no deck copy allowance remain in the database but are marked as not deck-selectable.

They are hidden from the main card grid unless **Show generated cards** is enabled. They remain accessible from the hover profile of cards that generate them.

The app uses both official `related_card_ids` and direct card-name references found in rules text to recover generated-card relationships.

## Search syntax

Normal text searches names, rules text, sets, class, type, rarity, traits, keywords, functional roles and custom tags.

Examples:

```text
storm
role:draw
role:"Board Clear"
keyword:Ward
trait:Officer
set:"Chronicle of Destiny"
related:"Bat"
```

## Custom data

```text
data/
├── official/
│   ├── cards.json
│   └── metadata.json
└── custom/
    ├── exclusions.json
    ├── packages.json
    └── tags.json
```

`official/` is generated automatically and should not be manually curated.

### Packages

`data/custom/packages.json` can define combo/package groups:

```json
{
  "packages": [
    {
      "id": "example-package",
      "name": "Example Package",
      "description": "Small engine used together.",
      "promptOnAdd": true,
      "cards": [
        { "id": 12345678, "count": 3 },
        { "id": 12345679, "count": 3 },
        { "id": 12345680, "count": 2 }
      ]
    }
  ]
}
```

When `promptOnAdd` is enabled, clicking one of the cards in that package opens a selector before the package is added.

### Custom roles and tags

`data/custom/tags.json` can supplement the automatic role inference:

```json
{
  "cards": {
    "12345678": {
      "roles": ["Finisher", "Combo Piece"],
      "tags": ["Engine", "Evolve payoff"]
    }
  }
}
```

### Global exclusions

`data/custom/exclusions.json` contains repository-wide exclusions. Personal exclusions are stored separately in the user's browser.

## Official source

Card metadata is imported from:

```text
https://shadowverse-wb.com/web/CardList/cardList
```

The importer sends:

```text
lang: en
```

English card images are generated from the returned hashes:

```text
https://shadowverse-wb.com/uploads/card_image/eng/card/{card_image_hash}.png
```

## Automatic updates

`.github/workflows/update-cards.yml` runs weekly and can also be triggered manually. It regenerates the official JSON files and refuses to commit a suspiciously small card database.

For a local refresh:

```bash
node scripts/update-cards.mjs
```
